# University Student Performance Management System

## Project Overview

The University Student Performance Management System is a beginner-level, console-based Python application that collects 
student academic information, calculates academic performance, assigns grades, and determines academic standing.

This project was developed to practise Python programming fundamentals through a practical academic scenario.

## Features

- Collects student name and department.
- Collects CGPA and carryover status.
- Accepts scores for three courses.
- Calculates total and average scores.
- Assigns grades based on the student's average.
- Determines academic standing using average score, CGPA, and carryover status.
- Displays a structured student performance report.

## Technologies Used

- Variables and data types

## Grading Criteria

| Average Score | Grade |
|---|---|
| 70–100 | A |
| 60–69 | B |
| 50–59 | C |
| 45–49 | D |
| 0–44 | F |

## Academic Standing Rules

- Passed with CGPA of 4.5 or above and no carryover: First Class Academic Standing.
- Passed with CGPA of 4.5 or above and a carryover: Academic Review.
- Passed with CGPA below 4.5: General Academic Standing.
- Failed: Academic Probation.

## How to Run the Project

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in PyCharm or another Python IDE.
4. Run `Student_performance_system.py`.
5. Enter the requested student information and course scores.

## Project Scope and Limitations

This is an introductory console-based application. It currently processes one student's record at a time and does not 
permanently store student records.

Future improvements may include support for multiple students, functions, file storage, databases, and a web-based 
interface.
